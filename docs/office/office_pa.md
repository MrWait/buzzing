# 文档业务 PRD — Phase A（MVP 基础可用）

## 1. 概述

### 1.1 目标

将在线文档系统从"能用"提升到"好用"：完整编辑器、协作反馈、文档管理与权限分享。作为**独立可用的产品**，Web 端覆盖全部核心场景，Flutter/SDK 提供入口和数据同步能力。

### 1.2 阶段构成

Phase A 由 4 个里程碑组成，覆盖企业级文档协作平台的**基础可用能力**：

| 里程碑 | 主题 | 用户价值 | 状态 |
|--------|------|---------|------|
| **M1** 编辑器完善 | 富文本编辑能力对齐主流产品 | 能写出结构化文档 | ✅ 主体完成 |
| **M2** 协作增强 | 多人协作的可靠性与可视化 | 协作时"看得见、感受到" | 🔲 待开始 |
| **M3** 文档管理 | 搜索、回收站、子页面、收藏 | 大量文档场景下能高效组织 | 🔲 待开始 |
| **M4** 权限与分享 | 成员管理、共享链接、只读视图 | 文档可控制传播范围 | 🔲 待开始 |

### 1.3 当前状态

| 模块 | 状态 |
|------|------|
| 后端 office 模块 | ✅ 已实现：spaces / docs CRUD、Yjs WS、定时持久化、JWT 鉴权 |
| SDK BizOffice | ✅ 基础接口就绪 |
| Flutter | ✅ 文档列表 + 空间树 + 跳转浏览器编辑 |
| Web 前端 | ✅ 登录、主页、编辑器（ProseMirror + Yjs），M1 编辑器功能已完成主体 |
| 数据库 | ✅ documents / document_spaces / document_members / files |
| 权限 | ⚠️ `document_members` 表存在但无 API |
| 测试 | ❌ 未建立自动化测试 |

## 2. Phase A 范围

### 2.1 包含

#### M1 — 编辑器完善（P0）
- 完整格式工具栏（粗/斜/下/删/行内代码/标题/引用/列表/任务/代码块/表格/链接/图片/清除格式）
- 任务列表 checkbox、代码块、表格、下划线/删除线
- 文档标题可编辑（TitleBar），debounce 保存
- 图片上传（点击 / 粘贴 / 拖拽）
- 链接 dialog（插入 / 编辑 / 移除）
- 斜杠命令菜单
- 完整快捷键（Ctrl+B/I/U，Ctrl+K，Ctrl+Shift+S/C，Tab）

#### M2 — 协作增强（P0）
- 在线协作者列表（头像 + 名字）
- 协作光标带用户名标签、选区高亮
- 保存状态指示器（已保存 / 保存中 / 未保存 / 离线）
- WebSocket 连接状态提示 + 指数退避重连
- 本地未同步编辑缓存（IndexedDB）
- BroadcastGroup 上限可配置

#### M3 — 文档管理（P1）
- 全文搜索（标题 + 内容 PG 全文检索，Cmd+K 唤起）
- 回收站（软删除 + 30 天保留 + 恢复 + 永久删除）
- 移动 / 复制 / 批量操作
- 星标收藏 + 收藏夹分组
- 最近访问列表
- 子页面（`parent_id` 层级） + 面包屑导航
- 空间管理（重命名 / 图标 / 颜色 / 拖拽排序 / 归档）

#### M4 — 权限与分享（P1）
- 成员管理 API（viewer / commenter / editor / owner 四级角色）
- 共享链接（token + 过期时间 + 访问密码 + 次数限制）
- 权限继承（空间成员自动继承到文档，可覆盖）
- 只读视图（角色为 viewer 时禁用编辑）
- 用户搜索器（复用 contact 组件）

### 2.2 不包含（Phase B/C 覆盖）

| 功能 | 归属 |
|------|------|
| 版本历史 | Phase B - M5 |
| Flutter 桌面编辑 / 移动端只读 | Phase B - M6 |
| 知识库层级（Wiki） | Phase B - M7 |
| IM 集成（消息卡片 / @提及 / todo 联动） | Phase B - M8 |
| 富组件（toggle / callout / TOC / 公式 / 图表） | Phase B - M9 |
| 企业安全（水印 / 密级 / DLP / 审计） | Phase C - M10 |
| AI 智能化（摘要 / 续写 / RAG） | Phase C - M11 |
| Yjs 集群化、自动化测试 | Phase C - M12 |
| 开放平台（Webhook / API / 机器人） | Phase C - M13 |
| 评论批注 / 模板 / 导入导出 | Phase C - M14 |

## 3. 用户场景

### 3.1 M1 — 编辑一个规范化的文档

1. 用户新建文档进入编辑器，直接编辑标题
2. 通过工具栏或 `/` 斜杠菜单插入标题、列表、任务、代码块、表格
3. 使用快捷键快速加粗、斜体、插入链接
4. 拖拽图片进入编辑器自动上传并插入
5. 所有格式改动实时同步给其他协作者

### 3.2 M2 — 感知协作状态

1. 用户打开一个多人协作中的文档，右上角看到其他 3 位协作者的头像
2. 别人的光标带着他的名字标签在文档中移动
3. 顶栏显示"已保存 2 秒前"，用户放心继续编辑
4. 网络中断时提示"离线，本地编辑将在恢复后同步"
5. 网络恢复后自动补齐所有本地未同步的改动

### 3.3 M3 — 组织海量文档

1. 用户按 `Cmd+K` 全局搜索关键词，跨空间跳转
2. 在文档树上把"周报"文档嵌套到"个人"父页面下
3. 面包屑导航显示 `个人 / 周报 / 2026-W29`
4. 误删的文档进入回收站，7 天内可恢复
5. 常用文档加星标收藏，主页"星标"分组可快速访问

### 3.4 M4 — 邀请协作与外部分享

1. 用户在文档点击"分享"，添加成员为 editor 角色
2. 生成对外共享链接（只读、7 天有效、限 100 次访问）
3. 外部访问者通过链接看到只读视图，无编辑按钮
4. 空间所有者一次性把整个空间的成员权限继承到所有文档
5. 用户在成员列表中把某人从 editor 降为 commenter

## 4. 非功能需求

| 需求 | 指标 |
|------|------|
| 协作延迟 | 同地域 < 200ms |
| 文档打开时间 | < 2s (含 Yjs 首次同步) |
| 并发编辑 | 支持 10 人同时编辑同一文档（Phase A），32 人（M12 后） |
| 单文档大小 | < 10MB |
| 数据可靠性 | 最多丢失 1s 编辑（Yjs 30s 定时持久化 + 断开即时保存） |
| 搜索响应 | < 500ms（万级文档规模） |
| 权限校验 | 每次 API 调用 < 20ms（含中间件） |
