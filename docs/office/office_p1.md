# 文档业务 PRD — Phase 1

## 1. 概述

### 1.1 目标

实现在线文档系统的基础能力。**Web 端作为独立产品**，包含完整的登录、主页、文档管理等页面，可直接在浏览器中使用。Flutter 端作为辅助入口，提供文档列表浏览和跳转编辑。为后续多维表格、管理后台和 Wiki 奠定基础。

### 1.2 当前状态

| 模块 | 状态 |
|------|------|
| 后端 office 模块 | 原型级：单文件 lib.rs，独立端口 8000，无 DB，无鉴权，单 Yjs Doc demo |
| Proto 定义 | 仅 `BIZ_OFFICE=7` / `DOC=5` / `DOC_FEED=12` 枚举占位，无消息无命令 |
| SDK | 无 office 相关代码 |
| Flutter | 无 office 页面 |
| Web 前端 | 不存在 |
| 数据库 | 不存在 |

### 1.3 范围

#### Phase 1 包含

| 功能 | 描述 | 优先级 |

## 2. 用户场景

### 2.1 Web 登录

1. 用户打开浏览器访问 `https://domain.com/office/login`
2. 输入账号密码登录
3. 服务端返回 JWT token，前端持久化存储
4. 后续请求自动携带 token

### 2.2 Web 主页 — 文档列表

1. 用户登录后进入文档主页 `/office`
2. 左侧展示空间目录树（"我的文档" 空间）
3. 右侧展示当前空间下的文档列表（标题、更新时间）
4. 用户可新建空间、重命名、删除

### 2.3 新建文档

1. 用户在 Web 主页或 Flutter 客户端点击「新建文档」
2. 输入标题，选择存放空间
3. 系统创建文档，直接进入编辑器

### 2.4 在线协作编辑

1. 用户点击文档进入编辑器 `/office/editor/:docId`
2. 编辑器加载文档内容，多人光标可见
3. 实时同步编辑内容，文档自动保存

### 2.5 文档管理

1. 用户在列表页对文档进行重命名、删除、移动空间
2. 所有操作在 Web 和 Flutter 两端同步可见

### 2.6 独立使用（无 Flutter）

1. 用户可通过纯 Web 方式完成所有操作：登录 → 文档管理 → 编辑
2. 不依赖 Flutter 客户端或 SDK

## 3. 非功能需求

| 需求 | 指标 |
|------|------|
| 协作延迟 | 同地域 < 200ms |
| 文档打开时间 | < 2s (含 Yjs 同步) |
| 并发编辑 | 支持 10 人同时编辑同一文档 |
| 文档大小 | 单个文档 < 10MB |
| 数据可靠性 | 最多丢失 1s 编辑内容 |
