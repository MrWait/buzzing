### 12.5 架构差异

Web 端与 Flutter 客户端的关键差异：

| 维度 | Flutter 客户端 | Web 端 |
|------|---------------|--------|
| 渲染 | `RTCVideoView` (flutter_webrtc) | `<video>` 标签 + `MediaStream` |
| 多窗口 | `desktop_multi_window` 子窗口 | 浏览器 Tab 天然独立 |
| 屏幕共享 | 桌面 Capturer 插件 | `getDisplayMedia` 原生 API |
| 信令 | Dart `Signaling` 类 | TypeScript `Signaling` 类 |
| 安装 | 需下载桌面应用 | 无需安装，浏览器打开 |
| 状态管理 | Riverpod | Pinia |
